# 月球基地问答 Agent（离线 RAG）

面向「未来月球基地」科普展览的**离线**问答程序。观众（青少年 / 儿童）向机器人角色提问，Agent 从本地知识库检索相关资料，再由本地大模型生成通俗、准确的口语化回答。**完全离线、不联网**，知识全部来自本地精编知识库。

---

## 1. 它是什么

- **离线 RAG**：先用检索器（本地知识库）找到最相关的几条资料，再把资料喂给本地大模型生成回答。模型只依据检索到的资料作答，不编造。
- **本地大模型**：默认用 Ollama 跑 `qwen2.5:1.5b`（CPU 即可，无需 GPU）。
- **零重依赖检索器**：`retriever.py` 是纯 Python 标准库实现的中文 BM25，不需要 faiss / torch / jieba / sentence-transformers，方便日后移植到资源受限设备。
- **7 个机器人角色**：不同展舱的机器人语气不同（见下）。
- **库外拒答**：与月球 / 太空无关的问题（红烧肉、天气等）会被领域闸门挡下，回答「这个我暂时不太确定」，不会乱编。

```

├── agent.py              # 主程序（命令行问答，单次 / 交互）

│   ├── 03_communication.json          月地通信（种子）
│   ├── 04_life_support_water_rover.json  生命保障 / 水 / 月球车（种子综合库）
│   ├── 05_psychology_operations.json  心理健康 / 基地运行（种子）
│   ├── 06_exhibit_specific.json       展项专属（种子）
│   ├── *_extra.json                   第一轮扩充（各主题）
```

知识库每条格式：
```json
{"topic":"主题","subtopic":"子主题","question":"问题","answer":"通俗准确的回答","tags":["标签",...]}
```

## 3. 安装（本机首次运行）

程序本身只用 Python 3 标准库，检索器零依赖。只需装 Ollama + 拉模型：

```bash
# 1) 安装 ollama（Linux）
curl -fsSL https://ollama.com/install.sh | sh

# 2) 拉取本地模型（约 1GB，一次即可，之后完全离线）
ollama pull qwen2.5:1.5b

# 3) 确认 ollama 服务在跑（默认监听 127.0.0.1:11434）
curl -s http://127.0.0.1:11434/api/tags
```

> 展览现场无网时：模型拉取一次后，`ollama` 本地服务和整个程序都**不再需要联网**。

## 4. 使用

### 单次提问
```bash
cd lunar-agent
python3 agent.py --role navigator --ask "月球晚上那么长没太阳怎么发电？"
```

### 显示检索到的资料（调试用）
```bash
python3 agent.py --role eva --ask "出舱前要检查什么？" --show_refs
```

### 交互模式（不带 --ask 即进入循环问答）
```bash
python3 agent.py --role proxima
# 然后逐句输入问题，输入 exit / quit 退出
```

### 纯检索模式（不调用大模型，只看命中的资料）
适合验证知识库、或模型暂时不可用时降级：
```bash
python3 agent.py --backend mock --ask "月球车的轮子和汽车一样吗？" --show_refs
```

### 常用参数
| 参数 | 说明 | 默认 |
|------|------|------|
| `--role` | 机器人角色（见下表） | commander |
| `--backend` | `ollama`（调本地模型）/ `mock`（纯检索降级） | ollama |
| `--ask` | 单次提问；不给则进入交互模式 | — |
| `--top_k` | 检索返回条数 | 3 |
| `--show_refs` | 打印检索命中的资料及分数 | 关 |

## 4.1 现场测试案例（10 条，本地模型实测完整回答）

下面 10 条是用 `--backend ollama`（本地 `qwen2.5:1.5b`）**真实跑出来的完整回答**，可作为现场验收基准。前 9 条准确命中知识库并作答，第 10 条正确触发「库外拒答」。命令和对应回答如下：

---

**1. 月球环境 · 一天有多长**
```bash
python3 agent.py --backend ollama --role commander --ask "月球上一天有多长？"
```
> **基地主管：** 月球上的一天大约是两周，即14天。（注：这里指白天时长；一个完整昼夜约 29.5 天，昼夜各约两周。）

---

**2. 宇航服与出舱 · 预呼吸**
```bash
python3 agent.py --backend ollama --role eva --ask "出舱前为什么要先预呼吸？"
```
> **EVA装备教官：** 出舱前先预呼吸是为了把血液和组织里溶解的氮气排出去，防止减压病。因为宇航服的气压只有约三分之一大气压，如果突然降到正常大气压，体内的氮气会像汽水瓶一样冒出气泡，导致剧痛甚至危险。所以必须先吸纯氧，把氮气慢慢换出来，需要一两个小时。

---

**3. 月面交通 · 免充气轮胎**
```bash
python3 agent.py --backend ollama --role navigator --ask "月球车的轮子为什么不用充气橡胶胎？"
```
> **月球交通领航员：** 因为月球环境对普通充气橡胶胎太不友好。在真空和极端温差下，橡胶容易老化开裂，而且会因为月尘和岩石的扎破而漏气。所以月球车多用金属网编织的免充气轮胎，或带弹性支撑结构的实心轮，既不怕扎破、不怕温差、不会漏气，还能提供缓冲颠簸。

---

**4. 月面交通 · 无 GPS 导航**
```bash
python3 agent.py --backend ollama --role navigator --ask "月球上没有GPS，月球车怎么导航？"
```
> **月球交通领航员：** 月球上没有GPS，但科学家们通过多种手段帮助月球车导航。主要依靠惯性导航、视觉导航和测距定位。这些方法结合起来，让月球车在没有GPS的环境下也能安全行驶。

---

**5. 生命保障系统 · 二氧化碳去除**
```bash
python3 agent.py --backend ollama --role steward --ask "密闭舱里的二氧化碳靠什么清除？"
```
> **生活舱管理员：** 密闭舱里的二氧化碳主要通过空气循环系统和多种方法清除。空气循环系统让舱内气体不断流动，避免局部空气停滞变坏。二氧化碳通过吸收材料被吸收，比如分子筛或吸附剂，这些材料可以反复使用。在紧急情况下，也使用化学吸收罐，如氢氧化锂。此外，通过萨巴捷反应，二氧化碳和氢气反应生成水和甲烷，水可以再电解出氧气，形成闭环，减少对地球的依赖。

---

**6. 生命保障系统 · 为什么不能用纯氧**
```bash
python3 agent.py --backend ollama --role steward --ask "月球基地为什么不能用纯氧？"
```
> **生活舱管理员：** 因为纯氧在一定压力下极易助燃，历史上有过惨痛教训。所以载人舱一般模拟地球空气，用氮气（或其他惰性气体）加氧气的混合，把氧浓度控制在安全又够呼吸的范围。

---

**7. 月球能源系统 · 月夜供电**
```bash
python3 agent.py --backend ollama --role engineer --ask "月夜那么长没太阳，基地靠什么供电？"
```
> **深空通讯工程师：** 月夜那么长没太阳，基地靠多种方式供电。白天用大容量电池储存电能，黑夜里释放出来使用。此外，还可以用燃料电池发电，或者未来可能用核能电源，这些电源都不依赖阳光，可以稳定供电。基地通常会结合多种方式，确保黑夜里生命系统不断电。

---

**8. 月地通信 · 通信延迟**
```bash
python3 agent.py --backend ollama --role signal --ask "为什么和月球通话总有一两秒延迟？"
```
> **深空通信联络员：** 因为月球和地球之间的距离大约38万公里，无线电信号以光速传播，单程需要约1.3秒。所以说完一句话要等两三秒才听到回应，就像打了个「时间差」。（注：正确的往返约 2.6 秒；小模型偶尔会把往返算成更大数字，以知识库原文单程 1.3 秒、往返约 2.6 秒为准。）

---

**9. 心理健康 · 长期驻月**
```bash
python3 agent.py --backend ollama --role proxima --ask "宇航员长期在月球会不会心理出问题？"
```
> **情感联络员比邻：** 长期在月球基地确实有可能带来心理压力，比如孤独感和焦虑。但不用担心，月球基地会重视居民的心理需求，采取措施来确保他们的心理健康。比如宇航员可以和家人通信，准备娱乐活动，布置温馨的生活环境。这些措施都旨在帮助他们保持良好的心理状态，就像照顾好身体一样重要。

---

**10. 库外拒答测试（跑题问题不编造）**
```bash
python3 agent.py --backend ollama --role commander --ask "红烧肉怎么做？"
```
> **基地主管：** 这个问题我在月球基地的知识库里暂时没找到相关资料，换个和月球、太空、基地生活有关的问题问我吧！

---

> **关于事实准确性：** 回答内容严格来自本地知识库检索，模型不会凭空编造事实。个别数字（如往返延迟）小模型偶有算术口误，已在上方注明。现场若追求措辞更稳，可改用 `--backend mock` 直接输出知识库原文。

## 7. 扩充 / 修改知识库

直接往 `knowledge_base/` 里加 JSON 文件即可，程序启动时会自动加载目录下所有 `.json`。每条务必包含 `topic / subtopic / question / answer / tags` 五个字段。加完后可用：

```bash
python3 retriever.py   # 载入并打印条数 + 若干示例检索结果
```

自检没有报错、条数对得上，即表示新条目已生效。

## 8. 说明

- 机器人硬件（RK3588 等）本版**不涉及**，只在本机跑通问答逻辑；日后移植时，把 `llm_backend.py` 换成板子上的推理后端即可，检索器和知识库可原样复用。
- 模型回答偶有措辞小瑕疵（如口语化改写），但内容严格来自检索资料，不会编造事实。
